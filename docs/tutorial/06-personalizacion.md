# 6. Personalización y reto

Configura zona, días, horario y capacidad para el ejercicio. Usa un identificador consistente de responsable o equipo: no se deduce identidad de nombres similares. Los cambios de zona conservan los instantes UTC; cambia su visualización, no el momento real.

## Reto: mejorar las propuestas con restricciones explícitas

1. Carga la demo y selecciona sus dos vencidas.
2. Genera desde mañana: la prioridad alta debe ir primero y el bloque fijo debe quedar libre de solapamientos.
3. Reduce capacidad y horizonte; una tarea sin hueco se explica, no desaparece ni se divide.
4. Aplica solo tras confirmar y reconocer que las fechas límite requieren revisión separada.
5. Modifica una tarea y genera nuevas propuestas: las anteriores no deben aplicarse.
6. Añade un bloque de permiso ficticio como tarea fija y comprueba que se respeta.
7. Completa una tarea y exporta ICS: solo se exportan pendientes programadas. Completar aquí no elimina un evento ya importado fuera.

Para añadir festivos explícitos, amplía esquema/configuración, buscador y aplicación defensiva conjuntamente. Escribe pruebas antes de afirmar que respeta el calendario del centro. No incorpores festivos, descansos o reglas laborales por suposición.

No programes actos terapéuticos ni uses datos de pacientes. Un uso institucional requiere revisión de riesgos, privacidad, accesibilidad y autorización del centro, independientes de la prueba técnica.
